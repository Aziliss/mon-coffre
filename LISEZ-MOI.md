# Mon Coffre — l'appli

## Mettre l'appli en ligne (une seule fois, environ 5 minutes)
1. Sur github.com, crée un nouveau dépôt **public** nommé `mon-coffre`.
2. Clique sur « uploading an existing file » et glisse **tout le contenu** de ce dossier : `index.html`, `manifest.webmanifest`, `sw.js` et le dossier `icons`. Valide avec « Commit changes ».
3. Va dans **Settings → Pages**. Dans « Branch », choisis `main` puis `/ (root)`, et enregistre.
4. Au bout d'une minute, ton appli est en ligne à l'adresse `https://TON-PSEUDO.github.io/mon-coffre/`.

## L'installer sur ton iPhone
1. Ouvre cette adresse dans **Safari**.
2. Touche **Partager**, puis **« Sur l'écran d'accueil »**, puis **Ajouter**.
3. Pépite apparaît sur ton écran d'accueil. L'appli s'ouvre en plein écran et marche même sans réseau.

## Tes données
- Elles sont enregistrées **sur ton téléphone**, dans l'appli. Tes versements actuels (558 €) sont déjà dedans au premier lancement.
- **Réglages → 💾 Sauvegarder mes données** télécharge un fichier de sauvegarde. Fais-le de temps en temps, et avant de changer de téléphone.
- **Réglages → 📂 Restaurer** recharge une sauvegarde.

## Mettre à jour l'appli plus tard
Remplace `index.html` dans le dépôt GitHub par la nouvelle version. Tes données restent sur ton téléphone. La mise à jour arrive au lancement suivant (ferme et rouvre l'appli si besoin).

## Bon à savoir
- L'adresse GitHub Pages est publique : n'importe qui peut ouvrir l'appli, mais chacun ne voit que **ses propres** données. Les tiennes ne quittent pas ton téléphone.
- La musique est une composition originale, générée en direct par l'appli.
- Pas de son ? Coupe le mode silencieux de l'iPhone.
